# App Icon Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an adaptive launcher icon to the Satoshi Signer app — a minimal secure element chip with checkmark on an amber-to-rose gradient.

**Architecture:** Four Android XML resource files (two vector drawables for foreground/background layers, two adaptive icon wrappers) plus a manifest update. No code, no logic, no tests needed — these are static resources.

**Tech Stack:** Android Vector Drawable XML, Adaptive Icon XML

**Spec:** `docs/superpowers/specs/2026-03-16-app-icon-design.md`

## Task 3: Create adaptive icon wrapper files

**Files:**
- Create: `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`
- Create: `app/src/main/res/mipmap-anydpi-v26/ic_launcher_round.xml`

Both files have identical content — they reference the same foreground/background layers and include the monochrome layer for Android 13+ themed icons.

- [ ] **Step 1: Create the mipmap directory and both wrapper files**

`ic_launcher.xml` and `ic_launcher_round.xml` (identical content):

```xml
<?xml version="1.0" encoding="utf-8"?>
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@drawable/ic_launcher_background" />
    <foreground android:drawable="@drawable/ic_launcher_foreground" />
    <monochrome android:drawable="@drawable/ic_launcher_foreground" />
</adaptive-icon>
```

- [ ] **Step 2: Commit**

```bash
git add app/src/main/res/mipmap-anydpi-v26/
git commit -m "feat: add adaptive icon wrappers with monochrome layer"
```

## Task 4: Update AndroidManifest.xml

**Files:**
- Modify: `app/src/main/AndroidManifest.xml:9-14` (add icon attributes to `<application>` tag)

- [ ] **Step 1: Add icon and roundIcon to the application tag**

Change the `<application>` opening tag from:

```xml
<application
    android:name="com.chaquo.python.android.PyApplication"
    android:allowBackup="false"
    android:label="@string/app_name"
    android:networkSecurityConfig="@xml/network_security_config"
    android:theme="@style/Theme.RemoteSigner">
```

To:

```xml
<application
    android:name="com.chaquo.python.android.PyApplication"
    android:allowBackup="false"
    android:icon="@mipmap/ic_launcher"
    android:roundIcon="@mipmap/ic_launcher_round"
    android:label="@string/app_name"
    android:networkSecurityConfig="@xml/network_security_config"
    android:theme="@style/Theme.RemoteSigner">
```

- [ ] **Step 2: Commit**

```bash
git add app/src/main/AndroidManifest.xml
git commit -m "feat: set launcher icon in manifest"
```
